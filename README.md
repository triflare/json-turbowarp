## Highlights

- Integrate JSON data parsing and manipulation into your projects, and handle strings and arrays.

## Overview

Based on Skyhigh173 and Mio's [original JSON extension](https://extensions.turbowarp.org/Skyhigh173/json.js), JSON is that extension modified for use in [Kamix](https://github.com/triflare/kamix), an OS runtime layer for PenguinMod, coded in [Triflare Fx](https://github.com/triflare/fx).
